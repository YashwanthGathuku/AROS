# WSL2

`aros doctor` and treat missing Podman as **UNSAFE/MISCONFIGURED**.

Recommended path:

1. WSL2 Ubuntu
2. Install Rust + Python 3.14 if available (3.13 is the lab floor; ADR-0003)
3. Install Podman rootless
4. Prove the five network invariants before claiming acceptance C
