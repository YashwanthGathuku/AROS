# Code of Conduct

## Our pledge

We pledge to make participation in AROS a harassment-free experience for
everyone.

## Our standards

- Be respectful and precise.
- Do not use AROS against unauthorized targets.
- Do not share exploit details against systems outside repository fixtures
  without a coordinated disclosure process.
- Assume good faith; challenge ideas, not people.

## Enforcement

Maintainers may warn, limit, or remove contributions that violate this
code or the project's security invariants.

This code of conduct is adapted from the spirit of the Contributor Covenant
2.1, simplified for an early research-tool project.
